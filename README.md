# She Safe – Smart Safety-Oriented Navigation System Using Crowd Analytics

## About the Project

She Safe is a smart navigation system designed to recommend routes using crowd-density analytics and safety-related information.

The project aims to analyse available location and crowd data to help users make more informed travel decisions.

## Objectives

- Analyse crowd-density data.
- Process and clean datasets using Python.
- Develop machine learning models for crowd-density classification.
- Compare routes using distance and estimated risk indicators.
- Visualize route information using interactive maps.

## Technology Stack

- Python
- Flask
- Pandas and NumPy
- Scikit-learn
- HTML, CSS and JavaScript
- SQLite
- MAP API's
- OpenStreetMap and Leaflet.js
