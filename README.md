# She Safe – Smart Safety-Oriented Navigation System Using Crowd Analytics

## About the Project

She Safe is a smart navigation system designed to recommend routes using crowd-density analytics and safety-related information.

The project aims to analyse available location and crowd data to help users make more informed travel decisions.

## Objectives

- Analyse crowd-density data.
- Process and clean datasets using Python.
- Develop machine learning models for crowd-density classification.
- Compare routes using distance and estimated risk indicators.
- Visualize route information using interactive maps.

## Technology Stack

- Python
- Flask
- Pandas and NumPy
- Scikit-learn
- HTML, CSS and JavaScript
- SQLite
- MAP API's
- OpenStreetMap and Leaflet.js

# She Safe
## Smart Safety-Oriented Navigation System Using Crowd Analytics

### Problem Statement

Women travelling through unfamiliar areas may face
difficulty evaluating routes based on crowd conditions.

Traditional navigation systems primarily focus on
distance and travel time.

She Safe aims to analyze historical crowd-density
data and provide alternative route assessments
to support more informed travel decisions.

### Proposed Solution

The system combines geographical route information,
historical crowd-density analysis and machine learning
to estimate crowd-density levels along alternative
routes and display the results on an interactive map.


## Project Objectives

1. Develop a web-based navigation application.
2. Analyze historical crowd-density information.
3. Perform data preprocessing using Pandas and NumPy.
4. Predict crowd-density levels using Machine Learning.
5. Generate alternative routes between locations.
6. Compare routes using crowd-density information.
7. Display route assessments through an interactive map.
8. Provide a simple and user-friendly interface.
