
# She Safe - Requirements

## Functional Requirements
1. Accept source and destination.
2. Generate alternative routes.
3. Display routes on a map.
4. Analyze historical crowd data.
5. Predict crowd-density levels.
6. Compare route assessments.
7. Store search history.

## Non-Functional Requirements
1. Performance
2. Security
3. Reliability
4. Usability
5. Maintainability
6. Scalability
